# noti — 휴대폰 알림 전송

## 왜 만들었나

빌드·야간 무인 시험처럼 오래 걸리는 작업을 걸어두고 자리를 비우면, 에이전트가 채팅에 결과를 적어도
사용자가 볼 수 없다. 끝났는지 확인하러 계속 돌아오거나, 막혀 있는 걸 몇 시간 뒤에 발견한다.
`noti` 는 그 순간 휴대폰을 울린다.

## 지원 채널

| 채널 | 준비물 | 특징 |
|------|--------|------|
| `discord` | 웹훅 URL | 만료 없음, 기본값 |
| `ntfy` | 앱 설치만 (가입 불필요) | 제일 간단, 토픽 이름이 곧 비밀키 |
| `telegram` | 봇 토큰 + chat_id | BotFather 로 발급 |

여러 개를 동시에 쓸 수 있다 (`NOTI_CHANNELS="discord,ntfy"`).

## 설치

```bash
~/KscTool/noti/noti.sh init      # 설정 파일 생성 + alias 등록
vi ~/.devtools/noti/config       # 웹훅 URL 붙여넣기
source ~/.bash_functions
noti test                        # 휴대폰에 뜨는지 확인
```

### 디스코드 웹훅 만들기

1. 디스코드에서 개인 서버 생성 (`+` → 직접 만들기 → 나와 친구용)
2. 알림받을 채널 우클릭 → **채널 편집** → **연동** → **웹후크** → **새 웹후크**
3. **웹후크 URL 복사** → `NOTI_DISCORD_WEBHOOK` 에 붙여넣기
4. 휴대폰 디스코드 앱에서 해당 서버 알림을 **모든 메시지** 로 켠다

`urgent` 레벨에서 본인을 멘션하려면 `NOTI_DISCORD_MENTION="<@내유저ID>"` 를 채운다.
(디스코드 설정 → 고급 → 개발자 모드 ON → 내 프로필 우클릭 → 사용자 ID 복사)
채널 알림을 꺼놨어도 멘션은 푸시가 뚫고 온다.

## 사용법

```bash
noti -t "빌드 완료" "609H 전체 빌드 성공, 이미지 준비됨"
noti -t "시험 중단" -l urgent "AP SSH 응답 없음 — 확인 필요"
tail -5 build.log | noti -t "빌드 실패" -l warn        # 파이프 입력 가능
noti -c ntfy,discord "두 채널 동시 발송"
noti conf                                             # 설정 확인 (비밀값 마스킹)
noti log 50                                           # 전송 이력
```

레벨: `info`(🔔) / `warn`(⚠️) / `urgent`(🚨 + 멘션).
종료코드: `0` 최소 한 채널 성공 / `1` 사용법·설정 오류 / `2` 전송 실패.

## 내부 동작

- 설정: `~/.devtools/noti/config` (권한 600). 웹훅·토큰이 들어가므로 **커밋 금지**.
- 이력: `~/.devtools/noti/history.log` — `시각 | 채널 | 레벨 | OK/FAIL | 제목/본문 앞 70자`
- 페이로드는 `jq` 로 만든다. 따옴표·개행·역슬래시가 섞인 로그를 그대로 붙여도 깨지지 않는다.
- ntfy 는 HTTP 헤더에 한글을 실을 수 없어 **JSON 발행 엔드포인트**를 쓴다.
- 디스코드 본문은 1900자에서 자른다 (API 상한 2000자).
- `curl` 타임아웃 15초. 실패해도 호출한 쪽 작업을 막지 않는다.

## 주의

- 알림 본문에 비밀번호·키를 넣지 말 것. 외부 서비스에 그대로 전송된다.
- 사내망 전용 정보는 제목만 보내고 상세는 PC 에서 확인하는 쪽이 안전하다.
- ntfy 공용 서버의 토픽은 이름을 아는 사람은 누구나 구독할 수 있다. 긴 무작위 문자열을 쓸 것.
